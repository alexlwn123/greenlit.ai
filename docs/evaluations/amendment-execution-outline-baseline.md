# Amendment Execution Outline Baseline

## What is restored

Comparator-informed actions are now merged into the amendment outline as
execution-ready work packages. Each package includes:

- sequence;
- priority;
- suggested owner role;
- filing amendment and research/verification work;
- concrete deliverables;
- dependencies on other work packages;
- reviewed subject-filing pages; and
- comparator filing pages and transferability labels.

The same metadata appears in the report interface and the downloadable Markdown
outline.

in parallel. The panel's final synthesis follows the underlying technical work
so its conclusion can reflect the completed evidentiary record.

## Download behavior

The amendment-outline download now includes, for each work package:

- sequence, priority, owner, and domain;
- amendment and research instructions;
- deliverable checklist;
- dependency IDs;
- subject PDF pages; and
- comparator PDFs, pages, and assessment classifications.

The original Part 1–6 amendment sections remain after the execution work
packages so finding-level traceability is preserved.

## Remaining limitations

- Owner roles are functional suggestions, not named assignments.
- The plan does not estimate duration, cost, or resource availability.
- Dependencies are deterministic and should be adjusted when internal records
  reveal that two packages can be combined.
- Completion status is not yet editable from the report.
