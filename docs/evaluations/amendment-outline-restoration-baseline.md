# Amendment Outline Restoration Baseline

## Change from the minimum build

The minimum build copied individual recommended actions into a flat list. The
restored outline now groups remediation work into the GRAS notice structure:

1. Part 1 — Identity, manufacturing, and specifications
2. Part 2 — Intended use
3. Part 3 — Basis for the conclusion
4. Part 4 — Safety evidence
5. Part 5 — Dietary exposure
6. Part 6 — Evidence synthesis and independent conclusion

Only sections with identified work are included.

## Traceability

Each section retains:

- the highest finding severity in that section;
- contributing analytical domains;
- linked finding IDs;
- finding-specific corrective actions;
- unresolved evidence-matrix questions; and
- deduplicated filing excerpts and PDF pages.

The downloadable Markdown outline includes priority, domains, actions, and
source pages. The report interface shows the same structure and source-page
tags.

## Safety boundary

The outline does not predict FDA action, promise a no-questions response, or
prescribe uncited study standards. It turns the report's existing grounded
findings into an organized remediation plan. Any new study design or regulatory
strategy still requires expert review.
